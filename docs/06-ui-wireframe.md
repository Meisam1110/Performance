## ۶.۴ مدیریت پرسشنامه

جدول با سه گروه ستون. خانه‌های زرد ورودی، خانه‌های خاکستری محاسباتی.

```
▌ ورودی کاربر   ▌ محاسباتی (غیرقابل ویرایش)

┌── شناسایی ──────────┬── پاسخ سؤالات ──────────┬─ ویژه ─┬── محاسبات ──────┐
│شماره│نام│واحد│JL    │ Q1  Q2  Q3  Q4  Q5      │☑  ۳۰۰  │امتیاز│کارانه│ضریب│
│  ۱  │...│مالی│3H    │[▼] [▼] [▼] [▼] [▼]      │        │ ۳٫۵۰ │۱۰۵٫۰۰│405 │
```

تغییر هر کشویی بلافاصله ستون‌های محاسباتی، نوار بالا و منو را به‌روز می‌کند.
ردیف نارنجی = زیر حد نصاب، ردیف قرمز = پاسخ ناقص، ردیف خط‌خورده = کنار گذاشته‌شده.

## ۶.۵ روش پرداخت کارانه

ستون‌ها دقیقاً به ترتیب شیت مرجع:

```
شماره│نام│واحد│JL│عدد گرید│تأثیر گرید│عدد ارزیابی│امتیاز عملکردی│امتیاز کل│
      دریافتی قبل از تغییرات│تغییرات معاون بخش│کارانه نهایی│وضعیت│توضیح
```

ردیف جمع در پایین جدول ثابت می‌ماند. کلیک روی هر ردیف پنل جزئیات را باز می‌کند.

---

## ۶.۶ پنل جزئیات محاسبه

دو ستونی؛ سمت راست مرحلهٔ پرسشنامه، سمت چپ مرحلهٔ پرداخت.

```
┌─ مشخصات فرد ────────────┐  ┌─ عدد گرید            ۳۰۰ ─┐
│ شماره پرسنلی      ۱     │  │ getGradeScore("3H") = 300 │
│ سطح شغلی (JL)    3H     │  │ ستون F — جایگزین VLOOKUP  │
│ وضعیت    تغییر معاون    │  └───────────────────────────┘
└─────────────────────────┘  ┌─ عبور از حد نصاب     بله ─┐
┌─ پاسخ سؤالات عملکرد ────┐  │ 3.50 > 2  ->  3.50        │
│ Q1 = متوسط  →  3        │  │ امتیاز کمتر یا مساوی حد   │
│ Q2 = متوسط  →  3        │  │ نصاب، کارانه را صفر می‌کند│
│ Q3 = زیاد   →  4        │  └───────────────────────────┘
│ Q4 = زیاد   →  4        │  ┌─ امتیاز عملکردی   ۴۰۲٫۴۲ ─┐
└─────────────────────────┘  │ 399.85 + 2.5711 = 402.42  │
┌─ امتیاز عملکرد     ۳٫۵۰ ┐  │ 244.25 / 95 = 2.5711      │
│ (3 + 3 + 4 + 4) / 4     │  └───────────────────────────┘
│ ستون K — Q5 وارد نمی‌شود│  ┌─ کارانه نهایی  10,000,000,000
└─────────────────────────┘  │ مبلغ تعیین‌شده توسط معاون  │
                             └───────────────────────────┘
    [تعیین مبلغ توسط معاون بخش]                    [بستن]
```

هر گام سه چیز دارد: مقدار، فرمول با اعداد واقعی، و ستون مرجع در فایل Excel.
عبارت‌های ریاضی چپ‌به‌راست و توضیحات فارسی راست‌به‌چپ رندر می‌شوند.
